# Heather McDonald — Concept 2

A single responsive cream, blush and berry website concept. The first Heather-McDonald repository is unchanged.

## Review

Open `index.html` directly, or run `python3 -m http.server 4173` from this folder and visit http://127.0.0.1:4173. No dependencies or build step. Resize the browser to review mobile. Navigation scrolls to Podcasts, Live shows and Shop; Contact opens Heather’s official contact section. Podcast, product and membership links open their real destinations.

## Included

- Exact requested headline and supplied pink-room portrait, preserved unchanged from the embedded image in `heather-approved-images-editor.html`.
- Real supplied Juicy Scoop and Juicy Crimes cover artwork.
- Apple Podcasts, Spotify, YouTube, and Patreon (labelled membership).
- Official tour calendar link; no invented or stale dates.
- Juicy Extras: verified hoodie, coffee mug and publisher links for both memoirs.
- Facebook, Instagram and TikTok icons only. No newsletter, email capture or social image feed.
- Semantic HTML, skip link, keyboard focus states, mobile menu with Escape support, reduced-motion support, local images and system fonts.

## Assets and provenance

`assets/heather-portrait.webp` is a byte-for-byte extraction of the first embedded WebP in Alison’s supplied approved-images editor. It is 402 × 352 pixels; a higher-resolution original would improve large-screen sharpness. No AI image regeneration or identity changes were made.

`assets/juicy-scoop.jpeg`, `assets/juicy-crimes.jpeg` and `assets/books.png` are copied unchanged from the original repository’s supplied assets. Hoodie and mug photographs were downloaded from the official shop product CDN. These are review assets; production reuse approvals are not established by this concept.
